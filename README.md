# 🐍 Curso de Python 3 - Do Básico ao Avançado

Repositório criado para registrar minha evolução e exercícios práticos ao longo do curso.

## 🎯 Objetivo
Desenvolver sólida base em lógica de programação, orientação a objetos, automações e desenvolvimento web com Python.

## 📚 Conteúdo do Curso
- **Lógica de Programação:** Variáveis, tipos de dados, condicionais, laços de repetição.
- **Programação Funcional e POO:** Funções, decoradores, classes, herança e polimorfismo.
- **Módulos & Automação:** Manipulação de arquivos, JSON, Web Scraping, Selenium.
- **Desenvolvimento Web & Banco de Dados:** Django, SQLite3 e MySQL.
